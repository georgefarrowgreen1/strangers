## Wholesale Royal Mail

Adds Royal Mail Click & Drop booking, label downloads, carrier scans and dispatch review to wholesale fulfilment. The Royal Mail page under Admin → Wholesale includes an admin-only switch for new bookings and encrypted, write-only fields for booking and tracking credentials. New bookings start off. Existing order, dispatch email and invoicing rules apply at handover.

Additive D1 migrations preserve existing orders and keep credentials out of JSON backups. The existing hosting encryption key enables credential entry in Admin. Royal Mail Worker settings remain available for connections without an Admin override.

Verified mobile and desktop Admin and packing flows, Node 22 carrier and credential tests, and a local upgrade from production’s current schema using simulated carrier responses.
