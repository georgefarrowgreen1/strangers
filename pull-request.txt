Adds Consumer (Preview) to the staff admin desktop sidebar and mobile More menu.

- Review test orders and update their status.
- Search saved customer profiles and manage coffee availability.
- Pause signed-in test checkout and check launch readiness.
- Limit the management API to staff admins and forward only allowed actions to the retail preview.

The management connection uses a matching `CONSUMER_ADMIN_TOKEN` runtime secret on the staff Worker and the retail preview. Admin displays a connection status until setup is complete.

Typecheck and 16 focused admin tests passed on the release branch. The Consumer workflow was also checked in Chromium at five widths from 320 to 1440 px. GitHub Tests is required before squash merge.
