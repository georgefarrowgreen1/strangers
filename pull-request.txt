## Consumer storefront and dashboard

Add the visual storefront editor and a Products page to Admin → Consumer (Preview). Admins can preview draft changes on phones and desktops, publish or restore a page version, and manage product images, retail pricing, sizes, grind options and stock.

The consumer shop, coffee finder and checkout use the managed catalogue. Checkout verifies prices and availability with the separate consumer order service. Removing a product archives it and preserves previous order totals and packing details.

The consumer service migrations and compatible service code must be active before this dashboard and storefront release.
