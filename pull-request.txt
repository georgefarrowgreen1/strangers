## Findings fixed

- Whole and partial wholesale tab clears now commit in a single guarded transaction. Staff and Admin send the order versions they reviewed, and stale reviews change no orders. A failed clear returns the operator to the review with the selection intact.
- Staff Wholesale writes now send the same live change counters as Admin and customer wholesale writes.
- Scheduled standing-order recovery, Slack, dispatch email, diary reminders, holiday reminders and QuickBooks jobs report failures independently. One failed job no longer prevents later jobs from running.
- Simultaneous backups use different storage keys and remain separately downloadable. Existing timestamp-only links still work.
- Dispatch dates and holiday quarters validate before date arithmetic. Duplicate holiday approval entries are rejected, and quarterly accrual groups shifts by person and day before calculating totals.
- Catalogue photo routes stay outside public asset handling, and the authenticated Admin photo response uses no-store.

## Verification

Reviewed Worker host routing, authorization, storage and backups, Diary and Rota functionality, staff and customer ordering, Admin, invoicing, insights, live updates, and notification/accounting integrations. Tested the fixes against local synthetic accounts, orders and provider fixtures, including transactional races and partial job failure. Checked dependency advisories, TypeScript and the Worker deployment dry run.

The production Tests workflow exercises the full API and browser suites on the release commit.
