Wholesale now supports supplier/VAT setup, reviewed invoice issuance and customer invoice access. Admins enter legal supplier details, explicit tax rates/price basis, numbering and payment instructions. A saved real order can be previewed without allocating a number, then explicitly issued once using atomic order/settings version checks. Invoice PDFs retain saved billing, delivery, VAT, totals and payment terms; exact retries recover the same invoice. Payment recording is separate and version checked, with no bank transaction. Customers see only their own issued invoices, outstanding/overdue amounts, due dates and PDFs in My orders, including after source-order deletion.

Migration13 adds native D1 invoice/settings/payment storage. Issued snapshots and monotonic numbering are immutable and included in backups. Supplier/tax values must be configured; none are invented. The native PDF uses the actual Strangers vector logo, website blue/navy colours and a clear totals panel, with required VAT fields and captured terms. The shared writer supports server generation, fixed issuance metadata and bounded long-text wrapping. No new service, secret, hostname, email or payment integration.

Desktop layouts use available workspace width, grouped wider customer/account editors and fixed title/save controls. Payment/default/status choices use native sheets that preserve unsaved fields, version, scroll and focus. Account-review notifications appear only as a count beside Customers; the old attention section is removed. Customer header/basket/catalogue layouts adapt to wider and shorter desktops, with scrolling basket items and reachable totals/Review.

Validation: `npm test` passed 144 API/PDF tests with typecheck; `npm run test:e2e` passed 61 browser tests (205 total). Coverage includes VAT/concurrency/ownership/payment/backup invariants, PDF logo/fields/pagination/geometry/byte stability, and desktop draft/focus/basket behavior. Worker dry build passed. Phone, iPad and 1280/1440/1920 px desktop layouts were reviewed in light/dark mode, with 32 additional desktop/iPad visual states.
