## Admin dashboard

- Overview groups scheduled dispatch work and diary deadlines in Due today and links to the wider fulfilment, payment and review queues.
- Wholesale adds a mobile section picker, section URLs with browser Back restoring filters, and a desktop order and packing preview. Order settings groups announcements and alerts. Customer approvals and custom coffee visibility are easier to find.
- Invoicing adds invoice and business search and queues for overdue, due soon and payments needing review. Insights separates Roast plan, Forecast and Sales and starts with the roast summary on mobile. The existing forecast and roast calculations drive these views.
- People has searchable account states and a full profile with account actions grouped together. Sickness adds name search and a follow-up filter. Sites link to diary and rota settings for the selected site. Activity adds date filters and error reference search. Security and Backups & exports surface the current status and common actions.

The views use the existing light and dark theme, permissions and versioned write flows. No migration, dependency or production configuration change is required.
