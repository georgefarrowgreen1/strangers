## Production architecture

- Run typechecking and API tests alongside three browser shards under the same required test check. Check the live version and sign-in boundaries after Cloudflare builds the merged commit.
- Add deployment-managed D1 migrations and a schema readiness check. Local and existing environments can initialise missing migrations during the managed rollout.
- Maintain daily order totals transactionally and cache the weekly sales, forecasts and roast plans in D1. Invalidate snapshots when their inputs change.
- Build versioned JavaScript and CSS as a unit, retain the preceding generation and verify the complete Admin boot path.
- Support independent dispatch email, Slack and QuickBooks queues with the durable ledgers and the five-minute recovery sweep.

Cloudflare deployment settings and queue provisioning are documented in `docs/production-architecture.md`.
