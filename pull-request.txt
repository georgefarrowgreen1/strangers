## Production architecture runtime release

- Maintain operational order totals transactionally and reuse saved weekly sales, forecasts and roast plans in Admin.
- Publish content-addressed browser assets and retain the preceding generation. The Admin loader accepts the versioned paths.
- Replace repeated cold-start schema setup with a read-only check when D1 already has the expected migrations.
- Keep the durable email, Slack and QuickBooks records and run recovery jobs independently. Include the deployment command and queue consumers for the managed rollout.

The existing required Tests workflow is used for this release. Publishing the parallel workflow and activating deploy-time migrations and queue bindings require the GitHub and Cloudflare access described in `docs/production-architecture.md`.
